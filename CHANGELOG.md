# Changelog

## 1.1.0 — 2026-10-13
По итогам ревью — четыре исправления.
- **Единый формат записей.** Агенты и реестр используют одну схему (`text`, `kind`, `source`, `locator`, `quote`, `defs`, `units`, `published`, `inputs`, `depends_on`; `claim` принимается как синоним `text`). `import` проверяет обязательные поля и неизвестные ключи и при любой ошибке не импортирует ничего. Добавлена команда `validate`; агенты проверяют свои файлы перед возвратом. Определения метрик, дата публикации и входные данные расчёта больше не теряются.
- **Версии утверждений.** Вердикты вынесены в `verdicts.jsonl` и привязаны к отпечатку версии (текст, источник, цитата, определения, хеши входных файлов и скрипта, отпечатки посылок). Команда `edit` создаёт новую версию, и утверждение возвращается в `pending`. Выводы (`inference` + `depends_on`) перепроверяются при изменении посылок. `verified` может поставить только проверяющий агент или пользователь, и только со ссылкой на отчёт.
- **Строже проверка и завершение.** Каждая фраза итога должна иметь `[Cn]` или `[~]`. Числа сверяются с текстом процитированных утверждений. Во фразах `[~]` числа запрещены. `phase done` запрещён; задача завершается только командой `finalize`, которая перепроверяет итоговый файл и наличие отчётов. Границы механической проверки описаны в README и VERIFICATION.
- **Карта проекта.** Ранее не разрешённые импорты (Python, JS/TS-алиасы, Godot `res://`, относительные ссылки) сохраняются и разрешаются заново при появлении новых файлов — и через хук, и через `sync`. Правило «не сканировать проект» заменено на «карта — первый источник, при неполноте расширять поиск».
- 19 тестов, включая воспроизведения всех четырёх сценариев из ревью.

## 1.0.0 — 2026-10-13
- Оркестратор `conduct`: триаж, ТЗ по шаблонам (research/build/analytics/general), подтверждение 1–4, маршрутизация по моделям, дисциплина токенов.
- Круговая верификация `verify`: реестр утверждений, независимые проверяющие, повтор только изменённого, лимит раундов, Stop-гейт.
- Карта проекта `codemap`: инкрементальная индексация по хукам, карточки модулей, `impact`.
- Журнал токенов `tokens`: по моделям и агентам.
- 9 субагентов: scout, reader, finder, formatter, cartographer (Haiku); builder, analyst, fact-checker, code-verifier (Sonnet).
- Проверено: `claude plugin validate --strict` (манифест, маркетплейс, агенты, скиллы), 11 юнит-тестов, живые прогоны в Claude Code 2.1.296 (хуки SessionStart/PostToolUse/Stop/SubagentStop; полный цикл analyst → fact-checker → render).
