# Откуда экономия и как её измерить

## Рычаги

| Рычаг | Механизм | Где |
|---|---|---|
| Дешёвые модели на объёме | Haiku: веб, чтение документов, поиск по коду, форматирование, карточки. Sonnet: код, расчёты, проверка | `agents/*.md`, таблица маршрутизации в `skills/conduct` |
| Короткие возвраты | каждый агент пишет объём на диск и возвращает ≤ 100–300 слов; оркестратор передаёт пути, а не содержимое | тела агентов, шаблон делегирования |
| Без сканирования репозитория | MAP.md + карточки + `impact` вместо glob/read всего дерева; Explore на Opus заменён на finder на Haiku | `skills/codemap`, хуки |
| Инкрементальная проверка | после первого раунда проверяются только изменённые утверждения | `skills/verify` |
| Внутренний язык — английский | ТЗ, делегирование, карточки, реестр — на английском, с пользователем — на русском | `skills/conduct` |
| Стабильный префикс | не менять CLAUDE.md и набор инструментов посреди сессии, чтобы не сбрасывать кэш промпта | `skills/conduct` |
| Триаж | простые вопросы без протокола | шаг 0 в `skills/conduct` |
| Fable только по запросу | на Pro он идёт из usage-кредитов | шаг 2 в `skills/conduct` |

## Измерение

`/conductor:tokens 7` показывает токены по моделям и по типам агентов (input, output, запись и чтение кэша), долю каждого и оценку в долларах по прейскурантным ценам из конфига. Оценка нужна для сравнения долей. Точный остаток лимита — во встроенной команде Claude Code `/usage`.

Предлагаемая методика оценки «до/после»:
1. Выберите 3–5 типовых задач (например, сравнение 5G-запусков операторов, фича в игре, отчёт по выгрузке).
2. Выполните каждую без плагина в отдельном проекте и зафиксируйте долю недельного лимита по `/usage`, время и число найденных потом ошибок.
3. Повторите с `/conductor:conduct`.
4. Сравните: расход лимита, долю делегированного (в отчёте), число ошибок, найденных после выдачи.

Ожидаемая картина: доля Opus в стоимости падает, доля Haiku/Sonnet растёт, а ошибок после выдачи становится меньше. На коротких задачах протокол может стоить дороже прямого ответа, поэтому триаж пропускает их.
